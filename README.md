# 数学表达式网页绘图器

支持一维曲线、二维曲面、三维点云、极坐标曲线，以及一重/二重/三重定积分。

## 极坐标示例

在网页的绘图类型中选择“极坐标曲线”，输入：

```text
表达式：1+cos(theta)
定义域：theta=0,2*pi
```

表达式表示 `r=f(theta)`，角度按弧度输入；定义域支持 `pi` 和 `e` 常量。

## 定积分示例

选择“定积分（一重 / 多重）”，填写被积函数和每个积分变量的有限包围盒：

```text
被积函数：x^2
积分包围盒：x=0,1
```

二重积分和三重积分分别增加 `y`、`z` 的范围。一般区域使用额外的不等式条件筛选包围盒，例如圆盘：

```text
被积函数：1
积分包围盒：x=-1,1; y=-1,1
积分区域条件：x^2+y^2<=1
```

页面会返回数值积分和网格细化差值估计，并在原图上标示有效区域：一重积分显示曲线与横轴间的阴影，二重积分在曲面上高亮区域，三重积分用橙色点标出有效空间区域。矩形/长方体范围会额外尝试符号积分；带不等式的一般区域暂只提供数值积分。所有积分均在浏览器本地计算，使用 Math.js 和 Nerdamer。

## 本地运行

```powershell
python app.py
```

访问 `http://127.0.0.1:5000`。

## Render 部署

在 Render 中将此仓库作为 Python Web Service 部署，并使用仓库中的 `render.yaml`。

生产启动命令：

```text
gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120
```

健康检查地址：`/health`。
